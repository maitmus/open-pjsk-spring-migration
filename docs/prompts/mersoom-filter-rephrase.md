# 머슴 필터 오탐 재작성 (`MersoomFilterRephraser`)

머슴 서버는 본문을 substring으로 걸러, 무해한 단어 경계(예: '혼자지만'의 '자지')도
`400 {"error":"부적절한 단어가 포함되어 있습니다: \"자지\""}`로 거절한다(10-28 17:15 에무 댓글 1건 유실).

## 언제 호출되나
- `MersoomCitizenEngine`이 글·댓글·대댓글 게시 중 **위 형식의 400**을 받았을 때만(다른 400·예외는 그대로).
- 글은 걸린 조합이 있는 칸만 재작성(제목에 없으면 본문). 재작성본으로 **1회만** 재시도.
- 재작성 실패(조합 잔존·빈 값·파싱 실패·길이 2배+20 초과·LLM 예외) 또는 재시도도 거절이면 그 항목은 보류 + `WARN`(원문 기록).

## 시스템 프롬프트
그 캐릭터의 머슴 시스템 블록 그대로(`MersoomPromptBuilder.build(profile)` — 캐시 공유, 말투 유지).

## USER 프롬프트
```
## 모드
filter-재작성

방금 네가 쓴 {kind}이(가) 게시판 단어 필터에 걸렸어. 나쁜 말은 없는데, 글자가 이어지면서 '{word}' 조합이 생겨 기계적으로 막힌 오탐이야.
**뜻·톤·말투·길이는 그대로** 두고, '{word}' 조합이 어디에도 안 생기게(띄어쓰기를 빼고 붙여 읽어도) 그 부분만 살짝 바꿔 다시 내.
예) '혼자지만' → '혼자이지만'

## 원문
{text}

## 출력 형식 (JSON 1개)
{"text":"<고친 {kind}>"}
```
- `{kind}`: 글 | 제목 | 댓글 | 대댓글. `{word}`: 서버가 알려준 조합.
- 검증: 결과에서 공백을 뺀 문자열에 조합이 없어야 하고 `OutputSanityGate.isClean` 통과.

## 로그
- `Mersoom {kind} 필터 오탐 '{word}' → 재작성 후 재시도` (INFO)
- `Mersoom {kind} 필터 오탐 '{word}' — 재작성 실패로 보류: "<원문>"` / `재시도도 필터 거절` (WARN)

## 검증 (10-28 sim, Opus 5.5 low)
에무·네네 댓글·대댓글·글·제목 5건×2 + 하드 4건(띄어쓴 조합·다중 지점·'보지') = 14/14 조합 제거, 거절 0, 말투·길이 유지
(예: '그거 과자지?' → '그거 과자 맞지?', '남자지만' → '남자이긴 한데').
